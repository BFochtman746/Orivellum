# Free Software Bill of Materials

| Component | Purpose | Cost model |
| --- | --- | --- |
| Lemonade Server | Local model serving and tool-capable OpenAI-compatible API | Apache-2.0 / local use |
| Node.js | Factory runtime | Free/open source |
| Git | Worktrees, checkpoints, rollback | Free/open source |
| Playwright | Browser/mobile verification | Apache-2.0 |
| Semgrep CE | Local static analysis | Open source Community Edition |
| Gitleaks | Credential/secrets detection | Open source |
| OSV-Scanner | Known-vulnerability scan of manifests/lockfiles | Open source |

This means zero subscription and API costs. Initial software/model downloads, electricity, storage, a public domain, and any future public hosting are separate real-world costs. The Factory does not require those to plan, build, preview, test, or package a website locally.
